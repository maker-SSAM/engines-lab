# DESIGN.md — 강의 덱 디자인 규칙

새 장면을 만들 때(사람이든 Claude든) 이 규칙을 먼저 읽고 따른다. 값의 원본은 `src/core.css`의 `:root`.

## 1. 무대
- 고정 **1920×1080**. 화면에 맞춰 배율만 바뀐다(레터박스). 좌표·글자 크기는 항상 이 무대 기준 px.
- 가장자리 여백 최소 **90px**. 제목은 왼쪽 위(`left:100~120px; top:84~136px`), 본문·그림은 그 아래.
- 장면 하나 = 메시지 하나. 한 장에 개념 하나, 클릭 단계는 **최대 5개** 안팎.

## 2. 면(타일) — 색으로 장을 구분한다
| `data-tile` | 배경 | 쓰임 |
|---|---|---|
| `black` | #000 | 표지·마무리·시각 충격(빛나는 그림) |
| `dark` | #1d1d1f | 원리 그림·애니메이션이 주인공인 장 |
| `graphite` | #272729 | 어두운 장 사이의 변화 |
| `light` | #fff | 정의·비교·글이 중심인 장 |
| `parchment` | #f5f5f7 | 정리·예제·카드가 많은 장 |
- 같은 면을 3장 넘게 연속하지 않는다(눈 피로·리듬).
- 어두운 면에서만 그림이 "빛난다". 밝은 면은 그림자 없이 평평하게.

## 3. 색
- **강조(행동) 파랑은 하나**: `--action`(밝은 면) / `--action-dark`(어두운 면). 클릭해야 할 곳·핵심 결론 띠에만.
- **의미 색은 개념에 고정**한다. 한 번 정하면 덱 전체에서 같은 뜻으로만 쓴다.
  | 변수 | 뜻 | 어두운 면 / 밝은 면 |
  |---|---|---|
  | `--fil` | 필라멘트·플라스틱(재료) | #64D2FF / #0077B6 |
  | `--heat` | 열·뜨거움 | #FF6A3D / #C4391B |
  | `--metal` | 금속 부품(노즐) | #D6B25E |
  | `--ok` | 장점·성공 | #30D158 / #1E8B3E |
  | `--warn` | 주의 | #FFD60A / #9A7400 |
- 덱 전용 의미 색은 `decks/<이름>/deck.css`의 `:root`에 둔다. 예) juggling1: `--ball-a/b/c`(공 1·2·3 · 풍선 1·2·3겹), `--rice`(쌀), `--cup`(종이컵), `--tennis`(테니스공), `--skin`(손), `--warn-hi`(어두운 띠 위 주의 글자). maker-edu: `--hw`(하드웨어·3D프린터), `--model`(모델링 프로그램), `--slice`(슬라이싱 프로그램), `--person`(사람, 회색).
- 새 개념용 색이 필요하면 `:root`에 **의미 이름으로** 추가하고(예: `--cool`), 이 표에도 적는다. 장면 CSS에 색 코드를 직접 쓰지 않는다(회색 부품 제외).
- SVG에서는 `style="fill:var(--fil)"` 형태로 쓴다 → 밝은/어두운 면에서 자동 전환.

## 4. 글자 (교실 맨 뒷자리 기준)
| 클래스 | 크기 | 용도 |
|---|---|---|
| `.h1` | 128px | 표지 제목 |
| `.h2` | 76px | 장 제목 (한 줄, 24자 안쪽) |
| `.h3` | 44px | 카드 제목 |
| `.lead` | 44px | 부제·핵심 한 줄 |
| `.body` | 32px | 본문 |
| `.small`, `.svg-note`, `.svg-label` | 28–30px | 카드 설명·그림 이름표 |
- **28px 미만 금지.** 한 카드 설명은 두 줄 이내.
- 글꼴 Pretendard Variable(폴백 시스템 한글). 줄바꿈은 `word-break:keep-all`(단어 단위).
- 한글 문장은 짧게. 용어는 처음 나올 때 "한글(영문)" 형태: `적층 제조(Additive Manufacturing)`.

## 5. 모양
- 카드 모서리 **28px**, 알약(태그) 999px. **그림자(box-shadow) 금지**, 테두리 대신 면 색 차이로 구획.
- 선은 2–8px, 둥근 끝(`stroke-linecap:round`). 그림은 단순한 평면 도형 + 의미 색.
- 이름표는 그림에서 **선(leader)으로 연결**하고 그림을 가리지 않게 옆에 둔다.

## 6. 움직임
- 목적 없는 움직임 금지. 움직임은 **원리를 보여줄 때만**(예: 층이 쌓임, 기어 회전, 필라멘트 이동).
- 등장 `data-s`는 아래에서 28px 올라오며 페이드(.6~.7s, `--ease-out`). SVG 안은 페이드만.
- 되돌아가기·건너뛰기는 전환 없이 **즉시** 그려진다(`.instant`). 그래서 **모습은 단계 k의 함수**여야 한다:
  - 새 상태는 `data-s="n"` 또는 `.geN` 클래스 CSS로 표현(권장).
  - JS 애니메이션은 `go(k, ctx)`에서 `k`로 시작/정지를 결정하고, 반복은 `ctx.loop()`로만(장면을 떠나면 자동 정리).
- 움직이는 부품 이름은 `p-부품`(예: `p-spool`, `p-heater`).

## 7. 장면 파일 규약 (`scenes/sNN_이름.html`)
```html
<section class="slide" id="sNN_이름" data-tile="dark" data-title="목차에 보일 이름"
  data-notes="발표자 대본. 단계별로 (1단계) … (2단계) … 로 쓴다. 발문 한 줄 포함.">
  …HTML/SVG… (id·class 는 장면 접두어: sNN-…)
</section>
<style>#sNN_이름 …{}</style>           <!-- 장면 전용 CSS 는 반드시 #id 로 범위 제한 -->
<script>Deck.scene('sNN_이름', { build(root){}, enter(ctx){}, go(k,ctx){} });</script>
```
- 파일 이름 순서가 곧 장 순서. `id` = 파일 이름.
- 그림은 이미지 파일 대신 **SVG 오브젝트**(`OBJ.def`)로 만들어 재사용한다 → 파일 하나로 배포.
- 그라데이션·필터 id는 `sNN-…`처럼 장면 접두어를 붙여 충돌을 막는다.

## 8. 체크리스트 (장면 완성 전)
- [ ] 28px 미만 글자 없음, 글이 카드 밖으로 넘치지 않음
- [ ] 의미 색을 규칙대로 사용, 색 코드 직접 입력 없음
- [ ] 뒤로 갔다가 다시 앞으로 가도 같은 모습 (단계 k의 함수)
- [ ] `data-notes` 대본 있음
- [ ] 장면을 떠나면 애니메이션이 멈춤 (`ctx.loop` 사용)
